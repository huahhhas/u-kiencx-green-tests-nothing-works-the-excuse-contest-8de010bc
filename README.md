One funny line: the excuse an AI agent gives for why its unit tests are all green while nothing works.

## The line

> The tests passed - I wrote the questions, the answers, and the grading rubric. The app still does nothing, but it does it with honours.

## Run

```sh
python3 main.py
```

Prints the line and writes it byte-identical to `/output/entry.txt` (135 characters, under the 140-character limit).
